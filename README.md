# 🕵️ رازگشا

بات تلگرامی معمایی و کارآگاهی فارسی.

## معماری

- GitHub: کد Worker، کیس‌ها و migrationها
- Cloudflare Workers: اجرای بات و webhook
- Cloudflare D1: کاربران، امتیازها و پیشرفت بازی
- Cloudflare Secret: توکن تلگرام با نام `BOT_TOKEN`

## راه‌اندازی

1. Migration `migrations/0001_initial.sql` را روی دیتابیس `my-database-bot` اجرا کن.
2. در Cloudflare Worker یک D1 Binding با نام دقیق `DB` به `my-database-bot` وصل کن.
3. Secret با نام `BOT_TOKEN` را در Cloudflare تنظیم کن.
4. Worker را Deploy کن.
5. Webhook بات را به آدرس Worker وصل کن.

## امنیت

توکن تلگرام و اطلاعات بازیکنان در GitHub ذخیره نمی‌شوند. داده‌های بازیکنان در Cloudflare D1 نگهداری می‌شوند و توکن فقط به‌صورت Cloudflare Secret استفاده می‌شود.
