# 🕵️ رازگشا

بات تلگرامی معمایی و کارآگاهی فارسی.

## معماری

- GitHub: کد Worker، موتور پرونده‌ها و migrationها
- Cloudflare Workers: اجرای بات و webhook
- Cloudflare D1: حساب‌ها، امتیازها، پیشرفت و داده‌های بازی
- Cloudflare Secret: توکن تلگرام با نام `BOT_TOKEN`

## امکانات

- 🔐 سیستم حساب کارآگاهی؛ بازی بدون حساب فعال ممکن نیست
- 📁 ۱۰ پرونده فارسی با درجه سختی مرحله‌ای
- 🔍 سرنخ‌ها، مظنون‌ها و معماهای چندگزینه‌ای
- 🗣️ لحن محاوره‌ای و خودمونی
- 🏆 امتیاز، سطح و رتبه‌بندی
- 🏅 دستاوردها
- 🎒 کوله‌پشتی و زیرساخت آیتم‌ها
- 🎯 مأموریت و جایزه روزانه
- 🔒 باز شدن پرونده‌ها به‌ترتیب
- 🛡️ ضدتقلب و جلوگیری از چندبار گرفتن جایزه پرونده
- 🧾 لاگ ساختاریافته و مدیریت خطای امن

## راه‌اندازی

1. Migrationهای `migrations/0001_initial.sql`، `0002_case_rewards.sql` و `0003_accounts_and_game_system.sql` را روی دیتابیس `my-database-bot` اجرا کن.
2. در Cloudflare Worker یک D1 Binding با نام دقیق `DB` به `my-database-bot` وصل کن.
3. Secret با نام `BOT_TOKEN` را در Cloudflare تنظیم کن.
4. Worker را Deploy کن.
5. Webhook بات را به آدرس Worker وصل کن.

## وضعیت

نسخه: `0.2.0`

رازگشا حالا پایه یک بازی کارآگاهی قابل توسعه را دارد؛ پرونده‌های بیشتر، سیستم‌های اجتماعی و قابلیت‌های پیشرفته‌تر می‌توانند روی همین موتور اضافه شوند.

## امنیت

توکن تلگرام و اطلاعات بازیکنان در GitHub ذخیره نمی‌شوند. داده‌های بازیکنان در Cloudflare D1 نگهداری می‌شوند و توکن فقط به‌صورت Cloudflare Secret استفاده می‌شود.
