# 🕵️‍♂️ Razgosha Telegram Themes

تم رسمی و غیررسمی رازگشا با هویت **Dark Detective Green**.

## 📱 Mobile

فایل `Razgosha-Dark-Detective.attheme` برای Telegram Android است.

در Telegram Android می‌توان فایل `.attheme` را از بخش تنظیمات تم وارد کرد.

## 🖥️ Desktop

فایل `Razgosha-Dark-Detective.tdesktop-theme` برای Telegram Desktop است.

در Telegram Desktop از بخش تنظیمات Appearance/Chat Background می‌توان تم را وارد کرد.

## 🎨 هویت بصری

- 🌑 پس‌زمینه ذغالی بسیار تیره
- 🟢 سبز کارآگاهی به‌عنوان رنگ Accent
- 🔎 حس اتاق تحقیقات و پرونده
- 💬 حباب‌های پیام سبز تیره
- ✨ متن‌های روشن و کنتراست بالا
- 🚫 بدون رنگ‌های تند و شلوغ
